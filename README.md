# ⚙️ Getting Started

Clone the repository:

```bash
git clone https://github.com/raunakcse25-star/DSA-in-Cpp.git
cd DSA-in-Cpp
```

Compile:

```bash
g++ filename.cpp -o output
```

Run:

```bash
./output
```

Windows:

```bash
output.exe
```
